Identity Fingerprints

Phones, watches and earbuds re-randomize their Bluetooth MAC about every 15 minutes to defeat tracking. The dongle hashes the rotation-stable part of each advertisement into a fingerprint and groups those changing MACs back into one device. A device that has cycled through several MACs while staying nearby is flagged ROTATING — the counter-surveillance signal that something is lingering and hiding its identity. The base station keeps the running history, so a device that quietly rotated for an hour is still listed after the fact.

Fingerprint history needs a base station running --history. Connected straight to the dongle, the live count still shows in the Rotating tile above.

Network

Move the base station onto a different WiFi. When the Pi recognises no network it falls back to its own aries-hotspot — join that from your phone to reach this page, then type the new network below. The Pi has a single radio that's busy hosting the hotspot, so it can't scan for you — enter the name yourself. Heads up: the moment it joins, the hotspot drops and this page will disconnect. Reconnect your phone to that same network (or Tailscale) after ~20 seconds and reopen aries.local:8080. A joined network is saved and auto-joined next time. If the password is wrong the hotspot comes back so the Pi is never stranded.

Network name — exactly as it appears on your phone, case-sensitive.

PCAP Capture

Records only the selected AP's 802.11 frames to a .pcap on the SD card — its beacons, the AP↔client handshake, and that network's data. No other network is captured. Start it from the Cap button on any row in the WiFi tab (default 60s), then briefly Deauth a client to force a WPA handshake. Only capture networks you own or are explicitly authorized to test.
